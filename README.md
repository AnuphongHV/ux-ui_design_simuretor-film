สร้างตาม mockup ที่ให้มา รองรับทั้ง **Desktop / Tablet / Mobile**

## ฟังก์ชันที่ทำไว้

### 1. คุณอยากได้ฟิล์มแบบไหน?
การ์ดให้เลือก 5 แบบ (เน้นกันร้อน / ขับกลางคืนบ่อย / เน้นความเป็นส่วนตัว /
อยากได้ฟิล์มใส / เอาแบบสมดุล) เมื่อเลือกแล้วแถบ **"แนะนำสำหรับคุณ"**
จะอัปเดตรุ่นและความเข้มที่แนะนำสำหรับบานหน้าและรอบคันทันที
ปุ่ม **"ใช้ชุดที่แนะนำ"** จะใส่ค่าลงภาพจำลองให้เลย

### 2. รถของคุณและตำแหน่งที่จะติด
เลือกประเภท/ขนาดรถ, ตำแหน่งที่จะติด (เฉพาะบานหน้า / รอบคัน / บานหน้า + รอบคัน)
และซันรูฟ — ถ้าเลือกติดเฉพาะจุดใดจุดหนึ่ง อีกฝั่งจะถูกปิดใช้งานและไม่คิดในสรุป

### 3. ดูบนรถของคุณ (สตูดิโอจำลอง)
* สลับ **ก่อนติด / หลังติด**
* เปลี่ยนมุมรถ **45 / 0 / 135 องศา** — แต่ละมุมใช้รูปจริงคนละไฟล์
  และมีพิกัดกระจกของตัวเอง ระบบจะระบายสีฟิล์มลงเฉพาะพื้นที่กระจกของมุมนั้น
  (0 องศา เห็นบานหน้า · 135 องศา เห็นรอบคัน · 45 องศา เห็นทั้งสองอย่าง)
* ป้ายมุมขวาบนบอกว่ากำลังปรับตำแหน่งไหนอยู่และเป็นรุ่นอะไร
* แถบสีให้เลือกความเข้ม 5 ระดับ (เดิม / 20 / 40 / 60 / 80) พร้อมสไลเดอร์ ใส ↔ เข้ม
* การ์ดสเปกแสดง TSER / VLT / UV ของทั้งสองตำแหน่ง

### 4. ชุดฟิล์มของคุณ
สรุปรุ่น แสงส่องผ่าน และ TSER ของทั้งสองตำแหน่ง
พร้อมปุ่ม LINE และปุ่ม **"คัดลอกข้อความสรุป"** (คัดลอกสรุปทั้งชุดเป็นข้อความ)

## Popup ทั้ง 2 ตัว (ตามลูกศรใน mockup)

ทั้งคู่ใช้ `<dialog>` ของ HTML มาตรฐาน — ปิดด้วย `Esc` หรือคลิกนอกกล่องได้

| Popup | เปิดจาก | ทำอะไร |
|---|---|---|
| **Price List ทั้ง 6 ซีรี่ส์** | ปุ่มแดง **"เลือกรุ่นฟิล์ม"** (มีทั้งฝั่งบานหน้าและรอบคัน) | แผงดำแสดง 6 ซีรี่ส์พร้อมช่วงราคา กดที่ซีรี่ส์เพื่อกางดูรุ่นย่อย เลือกรุ่นแล้วจะใส่ลงภาพจำลองและสรุปทันที ซีรี่ส์ของรุ่นที่ใช้อยู่จะถูกกางให้อัตโนมัติ |
| **ภาพมุมมองภายใน** | ปุ่มแท็บ **"ภาพมุมมองภายใน"** | ภาพจำลองจากที่นั่งคนขับ มีเส้นแบ่งลากเทียบ **ก่อน/หลังติดฟิล์ม** ได้ (ลากด้วยเมาส์/นิ้ว หรือปุ่มลูกศรซ้าย-ขวา) และสลับ **กลางวัน / กลางคืน** |

## การจำลองสีฟิล์มบนภาพรถ

กระจกแต่ละบานถูกวาดเป็น `<polygon>` ใน SVG ที่ทับอยู่บนรูปถ่าย
(พิกัดอยู่ใน `ANGLES` ของ `assets/js/data.js` ใช้ระบบพิกัด `1000 × 558`)
ชั้น SVG ใช้ `mix-blend-mode: multiply` เพื่อให้สีฟิล์มคูณกับรูปจริง
ได้ผลลัพธ์ที่ดูเป็นกระจกมากกว่าการวางสีทึบทับ

ความทึบคำนวณจากค่า VLT ของรุ่นที่เลือก (`alphaFor()` ใน `app.js`)
ส่วนโทนสีมาจาก `tone` ของแต่ละซีรี่ส์

**ถ้าจะเปลี่ยนไปใช้รูปรถรุ่นอื่น** ให้เปลี่ยนไฟล์ใน `assets/img/`
แล้วแก้พิกัด `front` / `around` ใน `ANGLES` ให้ตรงกับตำแหน่งกระจกของรูปใหม่

## ข้อควรทราบก่อนนำไปใช้จริง

* **ตัวเลขทั้งหมดเป็นข้อมูลสมมติ** — ค่า VLT / TSER / UV ช่วงราคา และปีรับประกัน
  ในไฟล์ `data.js` ใส่ไว้เพื่อสาธิตเท่านั้น ต้องแทนที่ด้วยข้อมูลจริง
* ลิงก์ LINE ใน `index.html` ยังเป็น placeholder `@YOUR_LINE_ID`
* ภาพจำลองเป็นการประมาณ ผลจริงขึ้นกับชนิดกระจกและสภาพแสงหน้างาน
* ยังไม่มีการคำนวณราคารวม — ตาม mockup ให้เจ้าหน้าที่เป็นผู้คำนวณ

## จุดที่ต่างจาก mockup เล็กน้อย (ตั้งใจ)

* **แถบสีมี 5 ช่อง ไม่ใช่ 4** — เพิ่มความเข้ม 20% เข้ามา เพื่อให้ทุกรุ่นที่อยู่ใน Price List
  เลือกได้จากแถบสีโดยตรง ไม่ต้องเปิด popup อย่างเดียว
* **ชื่อแผงเลือกฟิล์ม** — mockup เขียนว่า "ติดบานหน้า" กับ "บานหน้ารถยนต์"
  ซึ่งซ้ำความหมายกัน จึงเปลี่ยนเป็น "ฟิล์มบานหน้า" กับ "ฟิล์มรอบคัน"
  ให้ตรงกับคำที่ใช้ในขั้นที่ 2 และในสรุป
* **รุ่นที่แนะนำสำหรับรอบคัน** — mockup เขียน S-NC40-60 ทั้งสองช่อง
  แต่ความเข้มที่แนะนำของรอบคันคือ 60%/80% จึงแก้เป็น S-NC60-80 ให้สอดคล้องกัน
